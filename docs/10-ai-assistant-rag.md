# تشغيل الأسئلة الشائعة والمساعد الأكاديمي

## الصفحات والبيانات

- الطالب يشوف المحتوى المنشور في `/ar/dashboard/faq` أو `/en/dashboard/faq`. الصفحة والبحث يشتغلوا حتى لو المساعد مقفول.
- الإدارة تضيف وتعدّل المحتوى من `/ar/admin/faqs`. السؤال الجديد يبدأ كمسودة. النشر يظهره في صفحة الطالب وفي البحث اللي بيستخدمه المساعد. الموظف يحتاج صلاحية قراءة FAQ، وللتعديل يحتاج صلاحية كتابة كمان.
- زر تحميل الأسئلة الافتراضية يضيف 24 مسودة بالعربي والإنجليزي للحالات الشائعة ويتخطى الأسئلة الموجودة بنفس النص. راجع الإجابات وانشر المعتمد منها من صفحة الإدارة.
- أدخل السؤال وإجابته المعتمدة، والموضوع، والكلمات البديلة زي «فين نتيجتي»، «النتيجة»، و«إظهار الدرجات». لو محتاج دعم اللغتين، اعمل سجل عربي وسجل إنجليزي، مع كلمات البحث باللغة المطابقة للسؤال.
- جهّز إجابات معتمدة من شؤون الطلاب عن تسجيل الدخول واستعادة الحساب، البريد الأكاديمي، تسجيل المقررات، الامتحانات واللجان، الحضور، نشر النتائج، الشكاوى وقنوات الدعم. أرسل تاريخ سريان السياسات، والمستند الرسمي أو الرابط، واسم الجهة المسؤولة عن المراجعة. أي رسوم أو مواعيد أو شروط استثنائية تحتاج اعتماد قبل النشر. لو عندك لائحة PDF ابعتها كمرجع لصياغة المدخلات المعتمدة.
- اكتب الإجراءات العامة فقط في الـFAQ. البيانات الفردية تفضل موجودة في البوابة. لا تضف أرقام قومية أو كشوف درجات أو بيانات دخول إلى محتوى الـFAQ.

## طريقة الإجابة

المساعد يرجّح الأسئلة المنشورة باستخدام الكلمات المطابقة، مع تطبيع بعض صور الحروف العربية. يرجع الإجابة المعتمدة مباشرة. عند سؤال الطالب عن درجاته، السيرفر يستخدم مسار النتائج الحالي لنفس الحساب، بما فيه قيود النشر والإتاحة، ويعرض حتى ثمانية سجلات. تفاصيل الدرجات المسترجعة لا تُضاف لسجل المحادثة. المعدل والحضور والمواعيد الخاصة تتطلب الرجوع لصفحات الطالب المختصة حسب السؤال. Gemini يستقبل أجزاء من دليل المقررات النشطة وتعليمات عامة فقط، من غير رسالة الطالب الأصلية أو سجل محادثته أو تفاصيل درجاته. الأسئلة التي لا تجد مرجعًا مناسبًا تستخدم ردًا يوجّه لشؤون الطلاب.

## تفعيل الإنتاج على الـVPS

1. انشر النسخة المعتمدة والمساعد مقفول. جرّب نشر مسودة واحدة من الإدارة واتأكد أنها تظهر للطالب بعد النشر وتختفي لو قفلتها. ابدأ بالأسئلة اللي عندك لها إجابات معتمدة.
2. اختبر مفتاح Gemini ونموذج نصي متاح للمشروع في بيئة الاختبار. أضف القيم إلى `.env.prod` على السيرفر، مع صلاحيات قراءة مقيدة، ثم أعد إنشاء حاوية API من خلال نافذة الصيانة. قيم الإنتاج التالية نموذج إعداد. استخدم اسم نموذج صالح لحسابك. [دليل نماذج Gemini](https://aistudio.google.com/docs/models)

   ```dotenv
   STUDENT_AI_ENABLED=true
   GEMINI_API_KEY=<server-secret>
   GEMINI_CHAT_MODEL=<verified-model-id>
   ```

3. فعّل المساعد من إعدادات الإدارة بعد مراجعة المحتوى. لو كان زر الإدارة مفعّل قبل التحديث، اقفله قبل إضافة متغير التفعيل إذا لسه بتجهّز البيانات. راجع سؤالًا عربيًا وإنجليزيًا، وسؤال مقرر، وسؤالًا بلا مصدر، وسؤال «درجاتي» بحسابين تجريبيين. اختبر حسابًا لا تظهر له النتائج. حد الطالب خمس رسائل في 12 ساعة. قيمة `AI_MONTHLY_TOKEN_BUDGET` للمتابعة في لوحة الإدارة. اضبط حد الإنفاق من مزوّد الخدمة حسب سياسة المعهد.
4. لو ظهرت إجابات غير معتمدة أو زادت أخطاء المزود، اقفل المساعد من الإدارة فورًا. FAQ يفضل متاحًا. للتعطيل على مستوى السيرفر، غيّر `STUDENT_AI_ENABLED=false` وأعد إنشاء حاوية API في نافذة صيانة.

بعد تعديل `.env.prod` على نسخة سبق نشرها بالـworkflow، أعد إنشاء حاوية API بنفس وسم الإصدار الجاري. اتأكد من حالة Redis الأول، وشغّل أثناء نافذة صيانة لأن اتصال الجلسات المباشرة ممكن ينقطع مؤقتًا.

```bash
(
  set -e
  cd "$HOME/app"
  test -s .deploy/current-release
  export RELEASE_TAG="$(cat .deploy/current-release)"
  docker compose --env-file .env.prod -f docker-compose.prod.yml \
    up -d --no-deps --no-build --force-recreate --wait api
  curl --fail --silent --show-error http://127.0.0.1:4000/api/health
)
```

## أمثلة لمسودات البداية

| سؤال | إجابة للمراجعة | كلمات البحث |
| --- | --- | --- |
| أشوف النتيجة منين؟ | سجّل دخول بحسابك، وافتح «النتائج» من قائمة بوابة الطالب. هتظهر النتائج المتاحة لحسابك حسب قواعد النشر. | نتيجة، درجات، كشف درجات |
| أعرف مكان الامتحان إزاي؟ | افتح «مكان الامتحان» من بوابة الطالب. راجع «جدول الامتحانات» لمعرفة المواعيد المنشورة. | اللجنة، مقر اللجنة، مكان الامتحان |
| أبعت استفسار لشؤون الطلاب إزاي؟ | افتح «الشكاوى» من بوابة الطالب واتبع خطوات تقديم الاستفسار. | شكوى، استفسار، تقديم شكوى |
